# Куда сходить?

> **«Куда сходить?»** — информационная система для поиска достопримечательностей Санкт-Петербурга, просмотра подробных сведений об объектах и планирования прогулочных маршрутов по городу.

---

## О проекте

Приложение позволяет пользователю находить интересные места, добавлять их в персональный список «Хочу сходить», просматривать готовые экскурсионные программы и конструировать собственные маршруты.

### Основные возможности
- **Аутентификация:** Регистрация, авторизация и управление профилем пользователя.
- **Каталог мест:** Просмотр достопримечательностей Санкт-Петербурга с фотографиями, описаниями и координатами.
- **Аудиогид:** Прослушивание аудиоэкскурсий в приложении.
- **Избранное:** Добавление мест в личный список «Хочу сходить».
- **Маршруты:** 
  - Просмотр и сохранение готовых городских маршрутов.
  - Создание и редактирование собственных пользовательских маршрутов.
  - Отображение пути на интерактивной карте.
- **Персонализация:** Настройка параметров приложения.

## Архитектура и база данных

### Архитектурный шаблон (3-Tier Layer)

Взаимодействие компонентов построено по классической многослойной схеме:

$$\text{Controller} \longrightarrow \text{Service} \longrightarrow \text{Repository} \longrightarrow \text{MySQL}$$

1. **Controller:** Обрабатывает входящие REST-запросы пользователей.
2. **Service:** Содержит основную бизнес-логику приложения.
3. **Repository:** Отвечает за взаимодействие с базой данных через JPA/Hibernate.

---

### Структура базы данных

- `users` — данные для авторизации пользователей.
- `user_information` — персональная информация профиля.
- `user_settings` — настройки пользователя.
- `attractions` — реестр достопримечательностей (описание, медиа, координаты).
- `favorites` — объекты из списка «Хочу сходить».
- `routes` — реестр готовых и пользовательских маршрутов.
- `route_attractions` — связи достопримечательностей с маршрутами с учетом порядка следования.
- `favorite_routes` — сохраненные пользователем готовые маршруты.

## Маршруты и навигация

В системе предусмотрено два типа маршрутов:

1. **Готовые маршруты**  
   Заранее проработанные маршруты, добавленные разработчиками. Пользователь может изучать входящие в них точки и сохранять понравившиеся варианты.
2. **Пользовательские маршруты**  
   Индивидуальные подборки: пользователь самостоятельно выбирает достопримечательности и формирует порядок их посещения.

> **Построение маршрутов:** Планируется использование алгоритма поиска кратчайшего пути и интеграция с внешним картографическим API для построения маршрутов по реальной дорожной сети. Координаты объектов хранятся в базе данных.
