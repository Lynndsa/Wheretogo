##  Покрытие экранов и функций MVP 0.1

Макет включает в себя следующие ключевые экраны и пользовательские сценарии:

1. **Авторизация и Регистрация (`MVP-01`, `MVP-07`)**
    * Экран входа (`LoginActivity`).
    * Экран регистрации (`RegistrationActivity`).
    * Обработка ошибок ввода и сетевых сбоев.

2. **Главный экран и Карта (`MVP-02`, `MVP-03`, `MVP-04`, `MVP-05`)**
    * Отображение карты с возможностью масштабирования и прокрутки.
    * Отображение точек музеев и достопримечательностей (с обработкой ситуаций отсутствия данных в API / БД).
    * Переключение между режимами просмотра маршрутов (популярные / пользовательские).
    * Карточка подробной информации о маршруте и музее.

3. **Избранное (`MVP-06`)**
    * Список сохранённых пользователем маршрутов и музеев.
    * Переход к детальной информации по выбранному элементу.

4. **Личный кабинет (`MVP-08`)**
    * Профиль пользователя.
    * История и списки посещённых маршрутов и музеев.

5. **Навигация и Переходы (`MVP-07`)**
    * Плавные переходы между экранами, поддержка системной кнопки «Назад».
    * Сохранение состояния и вводимых данных на страницах.
